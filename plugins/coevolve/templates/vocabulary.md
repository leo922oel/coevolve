# Vocabulary

The fixed sets curation uses. Editing this is expected — translate it, or swap
the task types for the ones your work actually falls into. Keeping the sets
small and stable is what lets patterns show up; a free-text field never
aggregates into anything.

> Self-rated scales saturate. If almost every episode ends up "excellent" and
> "50-75%", the scale has stopped telling you anything — distillation checks for
> this each cycle. When it happens, treat those fields as a coarse screen and
> rely on calibrated confidence and the measured fingerprint instead.

## Task types
- feature — building something new
- bugfix — making something broken work
- review — reading someone else's change
- refactor — changing shape without changing behaviour
- integration — making two systems talk
- investigation — finding out how something works
- planning — deciding what to do
- tooling — building the thing that builds the thing
- writing — docs, reports, slides, comms
- ops — release, deploy, environment, CI

## Fit — how well suited the task was to working with AI
- excellent / good / mixed / poor

## Time saved versus the old way
- <25% / 25-50% / 50-75% / >75%

## Confidence that the output is actually correct
- high / medium / low

## Value type (a task may carry several)
- sped up work I already do
- did something I could not have done
- skipped boilerplate or lookup
- raised quality or confidence
- barely helped
